# تغييرات Masrofaty v2.33

## إصلاح أسعار الذهب

كان التطبيق يحسب قيمة الذهب بسعر `شراء` فقط، بينما الموقع يعرض `بيع` و`شراء`. لذلك كان الرقم يظهر مختلفًا عن الرقم الظاهر في الموقع.

التعديل الجديد:

- يعرض سعر `بيع` و`شراء` لكل عيار.
- يحسب القيمة الحالية الأساسية حسب `بيع الموقع` حتى تطابق الرقم الظاهر في eDahab.
- يعرض أيضًا قيمة البيع للتاجر حسب `شراء الموقع` عند وجود فرق.
- يستخدم سعر `الجنيه الذهب` المنشور في الموقع مباشرة بدل حسابه كـ 8 جرام فقط.
- يحدث السعر تلقائيًا مرة كل يوم عند فتح شاشة الذهب.
- زر `تحديث السعر` يعمل تحديثًا إجباريًا في أي وقت.
