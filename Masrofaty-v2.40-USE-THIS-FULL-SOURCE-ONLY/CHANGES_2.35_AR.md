# تغييرات Masrofaty v2.35

## شاشة الذهب

- الجزء الثابت أعلى الشاشة أصبح مختصرًا جدًا.
- الثابت الآن يعرض فقط:
  - الإجمالي.
  - قيمة البيع للتاجر.
  - إجمالي الوزن.
- باقي المحتوى يتحرك مع الاسكرول:
  - عنوان الصفحة.
  - حالة تحديث السعر.
  - أزرار إضافة الذهب وتحديث السعر.
  - الاختيارات السريعة.
  - تفاصيل البنود.

الهدف: إظهار بيانات الذهب بسهولة بدون أن يأخذ النص العلوي مساحة كبيرة من الشاشة.
