# تغييرات Masrofaty v2.41

- إضافة زر "صفحة الشخص والدفعات" داخل كارت كل دين.
- صفحة الشخص تعرض:
  - أصل الدين.
  - المدفوع.
  - المتبقي.
  - العملة.
  - تاريخ تسجيل الدين.
  - ملاحظات الشخص.
  - كل دفعة بتاريخها وملاحظتها.
- لو الدفعة لها سكرين شوت، يمكن فتحه من نفس الصفحة.
- كارت الدين في القائمة يعرض آخر 3 دفعات فقط حتى تظل القائمة خفيفة وسريعة.
- جدول الديون أصبح يقرأ `createdAt` و `updatedAt` لعرض تاريخ تسجيل الدين.
- الإصدار اتحدث إلى `versionName 2.41` و `versionCode 52`.
