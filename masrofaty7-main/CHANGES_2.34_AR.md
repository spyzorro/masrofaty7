# تغييرات Masrofaty v2.34

## إصلاح نزول إصدار قديم من GitHub

كانت المشكلة أن GitHub Actions يختار أول مشروع Gradle يجده داخل الريبو. لو كان موجود مشروع قديم مفكوك في جذر الريبو ومعه ZIP جديد، كان يبني المشروع القديم.

التعديل الجديد:

- يفك كل ملفات ZIP الموجودة في الريبو أولًا.
- يجمع كل مشاريع Gradle الصالحة من الريبو ومن الملفات المفكوكة.
- يقرأ `versionCode` من كل مشروع.
- يبني المشروع صاحب أعلى `versionCode` فقط.
- ينظف مجلد `final-apk` قبل نسخ APK الجديد.
- يطبع في Logs:

```text
Detected version
Prepared APK from version
```

## النتيجة المطلوبة

لو رفعت نسخة v2.34 وفي الريبو نسخ قديمة، الـ Action سيختار v2.34 لأنها أعلى `versionCode`.
